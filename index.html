About

I like data that has to earn its conclusions. My background spans civic tech — analyzing 311 complaints and housing court records to surface patterns of discriminatory code enforcement — freelance consulting on database migrations and reporting infrastructure for small businesses, and product analytics for a footwear recommendation engine used across two continents.

What ties it together: I care less about the tool and more about whether the output changes what someone does next. That's the standard every project on this site is built to.

Outside of work, I follow Formula 1 closely enough that I eventually turned race telemetry into a portfolio project — proof that if data exists, I probably want to poke at it.
